  • AI-assisted engineering: Adopted Claude Code in the team's workflow with a project context file (CLAUDE.md) encoding service boundaries, coding standards and security rules; used it to generate JUnit/Mockito test suites toward the 80% coverage gate, analyze legacy CTree code during migration, and speed up root-cause analysis of production issues, with every change human-reviewed and gated by CI.
  • Reliability engineering: Added Prometheus/Micrometer observability and an 80% coverage gate (JaCoCo + SonarQube) in CI/CD for a team with no dedicated QA; hardened endpoints with API-key auth, CORS, path-traversal defenses and RBAC; built a self-service configuration tool (React + Java) so ops staff manage batch schedules without engineering requests.
